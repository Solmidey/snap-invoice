# SnapInvoice

**Free professional invoice & quote generator.**  
Create clean invoices in seconds, download as PDF, no account required.

## Features
- Live preview while you type
- Multiple currencies (USD, EUR, GBP, NGN, CAD, AUD, INR…)
- Line items, tax, notes & payment terms
- One-click PDF (browser print)
- Fully responsive
- Zero signup for basic use

## Tech
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Client-side only (no backend required for MVP)

## Local development
```bash
npm install
npm run dev
```

## Deploy
Already set up for Vercel. Push to `main` → auto deploy.

---
Built for freelancers and small businesses who just need a clean invoice fast.
